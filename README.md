## Featured Projects

### 01. RAAH AI — Campus Navigation Platform

Designed to help students navigate university campuses and find classrooms, departments and other important locations.

**Key features and development focus:**

- Campus navigation and location guidance.
- Multilingual student assistance.
- Interactive campus map.
- Route-finding and navigation.
- Location management.
- Improving the overall campus experience.

**Repository:** [RAAH AI](https://github.com/jit7801/RAAH)

---

### 02. Proofly — RAG-Based Automation Tool

**An AI-powered content research and publishing pipeline.**

A project focused on automating the process of discovering information, retrieving relevant evidence, generating content and reviewing it before publication.

**Workflow:**

`Discover → Ingest → Retrieve → Draft → Review → Publish`

**Technology and development focus:**

- React and TypeScript.
- Tailwind CSS.
- Node.js and Express.
- Scheduled automation using node-cron.
- Retrieval-Augmented Generation.
- Weaviate and local memory.
- Server-Sent Events for real-time updates.
- Evidence-based content generation.

**Repository:** [RAG-based Automation Tool](https://github.com/jit7801/RAG-based-automation-tool)

**Live Demo:** [Open Project](https://rag-based-automation-tool.vercel.app/)

---
